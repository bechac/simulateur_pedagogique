À propos du modèle : les calculs reprennent les relations du tableur : Cp = 1,5 + 2,5 / √Qp (avec Q nominal converti en L/s), Qp = Cp × Qnom, S = Qp / vitesse ascensionnelle, D = √(4S/π), V = Qp × temps de séjour. La hauteur cylindrique est recalculée par bilan géométrique : Hcyl = V/S − Hcône/3. Le schéma illustre les principes de séparation ; il ne constitue pas une simulation CFD ni une validation réglementaire du dimensionnement.
