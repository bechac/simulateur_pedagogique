Comment les données changent-elles de forme ?

Les couches basses encapsulent les données reçues des couches supérieures.

Données — couche Application

Le message est produit par une application (par exemple une requête HTTP, une mesure MQTT ou une requête DNS). À ce stade, il s'agit du contenu utile à transmettre : texte, commande, mesure ou fichier.

Ce qu'il faut retenir : les données applicatives constituent la charge utile qui sera progressivement encapsulée par les couches inférieures.
À retenir : le modèle OSI est un modèle de référence. Dans une pile TCP/IP réelle, certaines fonctions OSI (notamment présentation et session) sont souvent prises en charge par les applications et les bibliothèques.

Encapsulation et désencapsulation

↓Émission : ajout d'informations de contrôle (en-têtes, et parfois remorque).
→Réseau : la trame est transmise vers le prochain équipement.
↑Réception : chaque couche interprète puis retire ses informations.

Attention : Ethernet transporte un paquet IP dans son champ « données ». Les adresses MAC servent à la livraison sur le lien local ; les adresses IP identifient les interfaces de bout en bout.

Ce que fait le commutateur

Un commutateur Ethernet de couche 2 apprend les adresses MAC sources et consulte sa table MAC pour décider sur quel port transmettre une trame. Il ne remplace pas le routeur et ne réalise pas le routage IP.
