Les coefficients σ et δ sont automatiquement sélectionnés selon l’angle exact ou la valeur tabulée la plus proche. Le coefficient μ reste réglable : ton classeur donne 0,0032 dans Feuil2 et 0,0046 dans Feuil1.
Relations de calcul reprises de l'annexe : Qr = Qpointe / (nombre de vis × 3600) ; N = 50 / D2/3 ; Qr = 1,15 × μ × N × D³ ; D = [Qr / (1,15 × μ × 50)]3/7 ; p = σD ; d = δD ; BL = (H + Fp) / sin(α) ; nombre de pas = BL/p ; Ph = ρgHQ. Consommation journalière = Pmoteur × durée × nombre de vis ; coût = consommation × prix du kWh. Rendement indicatif = Ph total / puissance moteur totale.
